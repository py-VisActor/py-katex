# py-visactor-katex 0.1.1

文档维护发行，安装：

```sh
python -m pip install py-visactor-katex==0.1.1
```

README/PyPI 介绍精简为安装、最小示例和静态能力边界。用户指南和 API 由 [docs/README.md](../README.md)进入；开发/AI agent 规则、来源与历史证据由[维护者目录](../development/README.md)进入。
