# py-visactor-katex 0.1.2

Adds native rendering on macOS 13 and later using Apple Silicon and Intel Canvas wheels. Math fonts remain bundled with KaTeX. The Python API and the installed `py-katex` command support PNG, SVG and PDF on CPython 3.13.

```sh
python -m pip install py-visactor-katex==0.1.2
py-katex 'x^2+y^2=z^2' --backend cpu -o formula.svg
```
