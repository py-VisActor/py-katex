First stable-version candidate for the native Python KaTeX core static renderer.

The uploaded wheel and source distribution have been reviewed on Windows in
clean external installations, including CPU/auto/GPU, five export formats,
bundled fonts, explicit resources, diagnostics and both CLI entry points.

This GitHub release remains marked as a prerelease while the exact same files
are validated by Windows/Linux CI and published to PyPI. The release workflow
promotes it after actual PyPI download, hash and installation verification.

Runtime changes from the accepted core-static implementation are limited to the
version constant. Browser HTML/MathML outputs, arbitrary CSS and standalone
contrib extensions such as mhchem remain outside the core-static release scope.

Assets include the wheel, sdist, `release-manifest.json` and `SHA256SUMS.txt`.
No API tokens are included.

PyPI distribution: `py-visactor-katex`; Python import: `py_katex`; CLI: `py-katex`. The former `py-katex` distribution name was rejected by PyPI name-similarity rules.
