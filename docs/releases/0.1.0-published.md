First stable release of py-katex: native Python TeX parsing, two-dimensional
mathematical layout and static PNG/JPEG/WebP/SVG/PDF rendering.

```shell
python -m pip install py-visactor-katex==0.1.0
```

- CPython 3.13 with `py-skia-canvas==0.1.0a18`.
- Twenty bundled math fonts and original KaTeX 0.18.11 metrics.
- Scoped macros, AMS/CD, equation tags, offline resources and static style adaptation.
- `py-katex` and `python -m py_katex` CLI entry points.
- Reviewed wheel and sdist validated in clean Windows/Linux CPU installations.
- Windows local CPU/auto/GPU validation and actual five-format output.
- PyPI files downloaded and checked against the reviewed SHA256 manifest, then installed again.

[PyPI](https://pypi.org/project/py-visactor-katex/0.1.0/) ·
[Documentation](https://github.com/py-VisActor/py-katex#readme) ·
[Changelog](https://github.com/py-VisActor/py-katex/blob/main/CHANGELOG.md)

The core-static scope excludes browser HTML/MathML output, arbitrary host CSS,
interactions and standalone contrib extensions including mhchem. Font rasterization
and natural dimensions need not be pixel-identical to a browser. Other Python
ABIs/architectures are constrained by the native dependency's available wheels.

PyPI distribution: `py-visactor-katex`; Python import: `py_katex`; CLI: `py-katex`. The former `py-katex` distribution name was rejected by PyPI name-similarity rules.
