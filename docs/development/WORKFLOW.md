# 开发工作指南

本指南面向维护者与 AI agent；用户指南从[用户目录](../README.md)进入。
当前规则摘要在 [AGENTS.md](../../AGENTS.md)，接口细节见[合同](../INTERFACES.md)与 [AST](../AST.md)。

## 按任务阅读

先查工作区状态，再确认当前用户要求、范围、owner 和允许的动作。
版本从 `pyproject.toml` 读取；运行状态从当前任务引用的记录读取。历史 `execution-state.json`、旧计划和发行授权不会自动成为新任务。
仅做文档时读公开 API/CLI、包元数据和相关用例，不重启整轮迁移或安装发行。
功能任务追溯固定源函数/宏/环境到解析、布局和实际绘制，列清消费者与已知边界。

## 实现边界

生产不依赖 Node、浏览器、DOM、JS 解释器或 `.local`，也不借私有 Canvas 表面。
原版 JS 只供独立 oracle。字体、源数据及移植算法保留版本、文件哈希和许可归属。
公共数学对象和跨线程接口为纯值；实际 Canvas、Context、字体对象属于创建线程。
未知语法、资源缺失和未支持可见分支明确报错/诊断；可见错误图不等于成功排版。
涉及 API/资源合同的变更需协调所有消费者，不能通过静默兜底或删除输入取得通过。

## 验证流程

按当前任务约定分离源码机械检查、来源独立测试设计、完整首跑、根因批修和同候选回归。
测试预期来自固定源、独立数值推导或真实原版，不由候选生成。
首次失败、实际命令/环境、候选与输入指纹、退出码和原图保存在独立运行目录。
闭合目录不可改写；修复后创建新运行，不能覆盖错误证据或把未执行检查写成通过。
绘制改动应核文字/符号、baseline、尺寸、边界、资源和实际图像，而非只看 AST/非空 bytes。
相关检查通过后，按接口影响扩展回归；发行包安装验证与工作区运行分别记录。
没有新改动或失败不重复无关全量测试。完成报告明确实际通过与仍未验证范围。

## 文档和外部操作

公开文档写用户能执行的安装/示例/API和限制，不把本机报告、阶段统计或交接指令放首页。
历史资料在[开发索引](README.md)分类保留；[旧 AGENTS 原文](archive/AGENTS-2026-11-07.txt)为迁移前字节快照，内部相对路径按当时仓库根解释，不是当前规则。
保留用户改动，禁止顺手 reset/clean。本地可逆准备和必要检查按任务自主执行，纯文档修改不额外触发安装或构建。提交、推送和发布依据当前用户授权，不由旧记录扩大权限，也不重复请求已经覆盖当前动作的授权。
